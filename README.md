## Sports-Scheduler (v2.0)

This is a production-ready Node.js application which aids in both the creation of sports by administrators and the creation of sports sessions by participants and also admins. Players and administrators can both join in the sports sessions that have been organised.

### 🧑‍🤝‍🧑 Core Application Features
- Players can create multiple sports sessions from available sports.
- Players can join multiple upcoming sessions but cannot join past sessions.
- Players can cancel sessions they have created.
- Admins can create and delete sports they manage.
- Admins can perform all player actions and exclusively access reports.
